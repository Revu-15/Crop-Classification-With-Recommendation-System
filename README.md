# 🌱 Crop Classification & Recommendation System  
A machine learning-based Streamlit web application that predicts the best suitable crop based on soil and weather parameters.

🔗 **Live App:** https://crop-classification-with-recommendation-systemrevanth15.streamlit.app/  
👤 **Developer:** Revanth Reddy  

---

## 🚀 Features
- ✔ Predicts the best suitable crop using ML  
- ✔ User-friendly Streamlit interface  
- ✔ Fast and accurate model  
- ✔ Clean UI with instant output  
- ✔ Deployed on Streamlit Cloud  

---

## 🧠 Machine Learning Model
The model is trained using:
- Nitrogen (N)  
- Phosphorus (P)  
- Potassium (K)  
- Temperature  
- Humidity  
- pH  
- Rainfall  

Algorithm used: **Random Forest Classifier**

The model is stored as:  
```
crop_model.pkl
```
